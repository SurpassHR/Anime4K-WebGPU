# Research notes and upstream shaders

- `anime4k-shaders/` — official Anime4K v4.0/v3.2 GLSL from bloc97/Anime4K (MIT).
- `weights.json` — parsed Restore CNN (S) + Upscale CNN x2 (S) weights, generated by `tools/extract_anime4k_weights.py`.

The aniwatch.top wrapper and site `app.js` are intentionally not bundled; see
`docs/site-implementation.md` for the behavior analysis.

The sibling `../NijiLucid` checkout is a separate MIT/LGPL project and is not
part of this repository.
